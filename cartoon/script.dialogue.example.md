# Two-voice dialogue example (for tts_dialogue.py)
> Each line is "NAME: text" or PAUSE (3 s of silence, e.g. for a quiz countdown).
> Map names to Kokoro voices on the command line: --voice MEI=bf_emma:b --voice BEN=am_michael:a

## S1 — Quick question
MEI: Ben, why does the kettle click off by itself?
BEN: Guess first. Is it a timer, or a sensor?
PAUSE
BEN: It's a sensor, of sorts. A little metal disc that snaps when the steam warms it.
MEI: So no chip at all? I like that.
